# FMS 개선점 정리 (2026-11-06)

기준 트리: `fms-work-order`, 지시서 파트 0.5·1·2 반영.

출처:
- 코어 검토(에이전트, 17건), 검증 쪽 검토(에이전트, 25건)
- Codex 리뷰
- 사용자가 전달한 목록(계약, 지도, 도메인, 의존, Gazebo, BLOCKED)

각 항목은 직접 확인했는지 표시했습니다.
- **확인**: 코드를 읽었거나 재현했습니다.
- **추정**: 읽은 코드에서 추론했고 재현하지 않았습니다.

이미 계획된 파트(4, 5, 5.5, 3, 7, 6, 8)는 구체적인 실패 경우가 있을 때만 적었습니다.

## 0. 이번에 찾아서 고친 것

| 무엇 | 어떻게 |
